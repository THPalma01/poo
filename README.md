# 🧠 Programação Orientada a Objetos

## 🧠 Descrição

Coleção de exercícios e exemplos práticos aplicando conceitos de Programação Orientada a Objetos.

## 🎯 Objetivo

Entender e aplicar os principais pilares da POO.

## 📚 Conteúdo

* Encapsulamento
* Agregação
* Composição
* Coleções
* Construtores
* Tratamento de exceções

## 🧠 Conceitos aplicados

* Organização em classes
* Reutilização de código
* Separação de responsabilidades
* Modelagem de sistemas

## ▶️ Como executar

Executar os exemplos em uma IDE compatível.

## 📌 Observações

Conteúdo focado em aprendizado progressivo dos conceitos de POO.
